# Engineering Decisions

## 1. Project Objective

The project implements a local semantic retrieval system for historical
Persian and Islamic texts from the OpenITI corpus.

## 2. Initial Design Principles

- Fully local execution
- Open-source components only
- CPU-compatible implementation
- Reproducible preprocessing and index building
- Clear separation between parsing, indexing, retrieval, and API layers
